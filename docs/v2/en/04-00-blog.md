# Blog

<kbd>Backend</kbd> ▶ <kbd>Blog</kbd>

Here you manage the entries of your blog: create, edit, sort and delete them.
You need the permission to publish content to access this section.

The blog documentation is split into several pages:

* **Blog** (this page) - overview, requirements, visibility and sorting
* [Post types](04-01-post-types.md) - the six kinds of entries and their fields
* [Options](04-02-post-options.md) - the sidebar and the <kbd>Settings</kbd> tab
* [SEO, URLs & RSS](04-03-post-seo.md) - metadata, slug, canonical URL and RSS feed


## Requirement: a blog page

Entries only appear in the frontend on a page that displays the blog. To set one up, select one or
more post types for a page under <kbd>Pages</kbd> (see [Pages](02-00-pages.md)). The page then shows:

* only entries of the **post types** selected there,
* only entries in the **language** of the page,
* only entries of the **categories** selected there (or all of them).

So you can create several blog pages, e.g. `/news/` with messages only and `/downloads/` with
download entries only.

How many entries are listed per page is set under <kbd>Settings</kbd> ▶ <kbd>Posts</kbd>
(default: 10). If there are more entries, a pagination is shown.


## The overview

The list shows all saved entries, newest first. For each entry you see:

| Column / detail          | Meaning                                                                                   |
|--------------------------|-------------------------------------------------------------------------------------------|
| #                        | The ID of the entry. It is also part of the URL of the detail page.                       |
| Star                     | Fix the entry on top or release it (see [Sorting](#sorting)). One click is enough.        |
| Priority                 | Can be changed directly in the list.                                                      |
| Type                     | The post type, color-coded.                                                               |
| Thumbnail                | The first selected image of the entry.                                                    |
| Title and description    | With the flag of the language. The description is shortened.                              |
| Dates                    | Created on, last edited on and the release date.                                          |
| Counters                 | For downloads the number of downloads, for links the number of clicks on the link.        |
| Categories and labels    | The assigned categories and [labels](04-02-post-options.md#labels).                       |

Drafts are highlighted in the list.

### Search and filter

* **Search:** You can add several search terms one after another. The search covers title,
  description, text and keywords. Each term can be removed individually.
* **Type:** In the sidebar you can limit the list to one or more post types. Clicking again removes
  the filter.
* **Categories:** You can filter by categories in the same way.

The filters are kept for your session.


## Create a new entry

Click <kbd>New</kbd>. Above the form you first choose the **post type**:

* Message
* Image
* Gallery
* Video
* Link
* Download (Files)

The form changes depending on the type. What each type can do and which fields it has is described
under [Post types](04-01-post-types.md). The type is set when you save the entry for the first time
and cannot be changed afterwards.

The form consists of:

* the **content tabs** of the respective type (e.g. <kbd>Intro</kbd> and <kbd>Content</kbd>),
* the <kbd>SEO</kbd> tab - see [SEO, URLs & RSS](04-03-post-seo.md),
* the <kbd>Settings</kbd> tab - author, source and RSS, see [Options](04-02-post-options.md#settings-tab),
* the <kbd>Addons</kbd> tab - additional fields from installed plugins (if any),
* the **sidebar** on the right - see [Options](04-02-post-options.md).

New entries are saved as a **draft** by default. Only when you set the status to <kbd>Public</kbd>
can all visitors see it.


## When is an entry visible? {#visibility}

An entry appears for regular visitors only if **all** conditions are met:

1. The status is <kbd>Public</kbd>.
2. The release date has been reached.
3. There is a blog page in the language of the entry that shows its post type and (at least) one of
   its categories.

Logged-in administrators additionally see drafts in the list - with a notice that the entry is a
draft. Administrators can open the detail page of a draft or of an entry that is not yet released
as a preview; everyone else gets a 404 error.


## Sorting in the frontend {#sorting}

The order of the entries on a blog page results from:

1. **Fixed on top** - fixed entries always come before all others.
2. **Release date** - newer days first. Only the **day** counts, not the time.
3. **Priority** - within the same day, an entry with a higher priority is placed higher.
4. **ID** - with equal priority, the most recently created entry comes first.

So if you want to put several entries of one day in a certain order, use the priority. If an entry
should stay at the very top, fix it.


## URLs of the entries

In the list, each entry links to its detail page. The URL is made up of:

```
/<page>/<slug>-<ID>.html
```

e.g. `/blog/my-first-entry-12.html`. The page with the type of use *Display Posts / Products / Events*
in the matching language is used as `<page>`. If there is none, the visitor stays on the blog page
on which they clicked the entry.

Categories have their own URLs below the blog page, e.g. `/blog/news/`.

More about the slug, the main category page and the canonical URL can be found under
[SEO, URLs & RSS](04-03-post-seo.md).


## Delete entries

The delete button in the list removes an entry permanently. Its tag assignments and its RSS entry
are deleted as well. For a **gallery**, all uploaded images of the gallery are deleted too. The XML
sitemap is updated automatically.
