# SwiftyEdit Documentation

Thank you for choosing SwiftyEdit.

This documentation contains all the important information you need to quickly find your way around—
from setup to using individual functions.

It is designed to help you work efficiently with SwiftyEdit and find answers to your questions.

## What you'll find here

The documentation is organized into the following areas:

* **[Installation](01-01-installation.md)** and **[Basics](01-02-basics.md)** - get SwiftyEdit up and running in minutes and learn the basic operation of the backend.
* **[Pages](02-00-pages.md)** - create pages, sort them, assign a usage type, and fill them in with different [content editors](02-01-content-editors.md).
* **[Snippets](03-00-snippets.md)** - reusable text blocks for pages, posts, products and e-mails.
* **[Blog](04-00-blog.md)** - publish messages, images, galleries, videos, links and downloads.
* **[Shop](05-00-shop.md)** - create and sell products, including price groups, features, options, filters and order management.
* **[Events](06-00-events.md)** - create and manage events, including guest lists.
* **[User management](07-00-user.md)** - accounts, permissions and groups for your users.
* **[Settings](08-00-settings.md)** - every global SwiftyEdit setting in one place.
* **[Developer](09-00-developer.md)** - build your own themes and plugins, tap into hooks, and find out how to contribute to SwiftyEdit yourself.

## About this documentation

To help you understand which area of the backend is being discussed,
the navigation path is usually displayed at the top of the page.
For example, it might look like this:

<kbd>Backend</kbd> ▶ <kbd>Pages</kbd> ▶ <kbd>New</kbd>

Each `<kbd>` box names something you'll actually see and click in the ACP; the arrow shows the
order you click through them in.

When discussing how and what data to enter, we display input fields as follows:


| Field       | Type     | Description               |
|-------------|----------|---------------------------|
| Username    | Text     | Name of the user          |
| Country     | Select   | Select your country       |
| Description | Textarea | Detailed description      |
| File        | File     | File upload               |
| Newsletter  | Checkbox | Subscribe to newsletter   |
| Gender      | Radio    | Please select your gender |
